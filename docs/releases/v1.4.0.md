# v1.4.0 (2026-08-17)

## 概要

- 水位の位況・流量の流況を、取得済みデータからGUIで算定できるようにしました。
- 対象種別に応じて、画面ラベルとExcel出力見出しを動的に切り替えるようにしました。
- 既存の取得GUIと後処理GUIを、ランチャーから選択できる構成に統合しました。

## 主な変更

- ランチャーに「水文統計（位況・流況）」を追加しました。
- 後処理GUIで次を指定できます。
  - 水位（位況）または流量（流況）
  - 必須の時間データ（`_H`）
  - 任意の日データ（`_D`）
  - Excel出力先、任意のParquet出力先
- `_WH` / `_QH` のファイル名から対象種別を初期推定します。最終的な対象種別はGUIの選択値を使用します。
- 後処理CLIに`--metric water_level|discharge`を追加しました。省略時は水位として従来互換を維持します。
- 流量選択時は、`流況豊水流量`、`流況平水流量`、`流況低水流量`、`流況渇水流量`、`最大流量`などの見出しを出力します。
- 取得処理は従来どおり既存の取得GUIで行い、後処理GUIは取得済みファイルを入力とします。
- PyInstallerのonedir/onefile配布物に後処理GUIを含めました。

## 互換性・注意事項

- 既存CLIで`--metric`を指定しない場合は水位として処理されます。
- 雨量の位況・流況後処理は今回の対象外です。
- リリース成果物はタグPush後のGitHub ActionsでWindows向けにビルドされます。

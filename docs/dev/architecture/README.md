# Architecture


このフォルダは「どう構成するか」を置く。

- `overview.md`: architecture 配下のハブ
- `entrypoints.md`: `main.py` を含む起動経路の正本
- `water_info.md`: `src/water_info/` の責務と処理の流れ
- `water_info_dam.md`: ダム諸量の専用取得・品質保持・年別出力・GUI
- `water_info_gui.md`: 取得条件・共通出力先・非同期実行・結果の画面構成
- `jma_rainfall_pipeline.md`: `src/jma_rainfall_pipeline/` の責務と処理の流れ
- `river_meta_rainfall.md`: `src/river_meta/rainfall/` の責務と処理の流れ
- `hydrology_graphs.md`: `src/hydrology_graphs/` の責務と処理の流れ
- `water_info_acquirer.md`: `src/water_info_acquirer/` の責務とランチャー構成
- `postprocess_gui.md`: 位況・流況後処理GUIの画面構成と責務分割

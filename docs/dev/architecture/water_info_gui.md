# 取得GUIの構成

要件: [取得GUI](../requirements/water_info-gui.md)

- `ui/app.py`: 画面配置・共有状態・入力検証・対象切替・結果表示・メインスレッドでのキューポーリング。
- `ui/forms.py`: 水位等の年月・項目フォーム、ダムの日付フォーム。要求モデルへ変換し、通信や書込をしない。
- `ui/help_content.py`: 対象に応じた説明と品質・出力形式の案内。
- `ui/styles.py`: この画面専用のttkスタイル。ランチャー・他アプリのテーマを変更しない。
- `service/acquisition.py`: 両対象の実行計画・進捗・結果を統一した取得ユースケース。GUI依存なし。
- `ui/execution.py`: 上記サービスをワーカーへ渡し、進捗・結果・終了をキューへ積むコントローラー。従来の実行補助も互換維持する。
- `entry.py`: 既存の取得ラッパーに出力先・中止判定を渡せるようにし、既定動作は維持する。

観測所・対象別条件・共通出力先を検証して実行計画を固定し、編集を無効化して開始する。結果は観測所単位で蓄積し、UIは成功/品質注意/部分取得/失敗/中止を表示する。サービスはTkウィジェットやStringVarを参照しない。

ダム専用パネルにあった出力先・ワーカー・進捗表示は共通画面へ統合する。旧 `dam_panel.py` はフォームの互換名のみを保持し、独立した実行画面は置かない。

画面レイアウト:

```text
見出し                                      使い方
┌観測所一覧────────┐ ┌取得条件────────────────┐
│コード入力・追加    │ │対象・項目・期間・補足              │
│複数貼り付け・削除  │ └──────────────────────┘
│一覧               │ ┌出力────────────────────┐
│                   │ │フォルダ参照・形式・保存構成         │
└─────────────────┘ └──────────────────────┘
進捗・設定概要                         中止 / 取得開始
結果一覧（観測所・状態・概要）          Excel / フォルダを開く
選択した結果の詳細
```

# ダム諸量のGUI取得・整理 要件

## 背景・目的

水文水質データベースのダム諸量を、既存の水位・流量・雨量とは区別してGUIから取得する。
2026-10-27、調査・GUI対応案についてユーザーの実装承認を受けた。実データの依頼対象は長安口ダム `608061288803010`、2009-01-01〜2024-12-31。

## スコープ

- 任意期間検索の時間値5項目（流域平均雨量・貯水量・流入量・放流量・貯水率）を一括取得する。
- GUIの取得対象表示は「水位・流量・雨量」「ダム諸量」とする。「通常観測」というサイトにない名称は使わない。
- 直近10分値、日集計、グラフ、位況流況後処理への接続は対象外。

## 入力

観測所記号、開始日・終了日（元ページの日付、両端を含む）、出力先、Parquet出力の有無。
31日超の期間も受け付け、内部で31日以内に分割する。年跨ぎ・閏日を扱う。

## 出力

- 1観測所・要求期間で1冊のExcel: 元日付の年を名前にした時間値シート、元値と属性、品質件数、出典、取得区間と失敗内容。
- 全期間CSV、任意のParquet（ダム専用の横持ち形式）。年別のファイルは生成しない。
- 全期間・年別の件数と品質を記録する取得結果JSON。取得元ファイルと取得条件を保存し、中断後に再利用できる。
- 年ごとの公開行数と項目別の品質件数を一覧できる「年別品質」シートを同じExcelに含める。
- 期待される時間値行が取得されなかった場合も欠落を明示する。途中失敗は全期間成功と表示しない。

## 制約

- 元日の01:00〜24:00を取得単位とし、24時を翌日00:00に正規化する。年末24時も要求元日の年に残す。
- 各項目の原値・原属性を保持する。`$`は欠測、`-`は未受信、`#`は閉局。これらと未知属性の整理値は空欄にする。通常の0は0のまま残す。
- 属性なしでも非数値は欠測として扱う。未知属性を正常値としない。
- 流域平均雨量の単位はmm/h、貯水量は10^3 m3、流入量・放流量はm3/s、貯水率は%。
- 今回の取得では時間意味を推定して積算・平均しない。Parquetは標準の瞬間値・区間値契約へ自動変換しない。
- サーバーへのアクセスは既存の間隔制御・再試行を使い、直列に行う。

## 完了条件

- GUIからダム諸量を選び、条件指定・取得・進捗確認・出力先確認まで行える。
- 31日制限、閏日、24時、品質属性、失敗・再開、年別出力が検証される。
- 通常の水位・流量・雨量取得を回帰確認する。
- 依頼された2009〜2024年の全期間取得を実行し、未取得区間やデータ品質を明記した成果物を残す。

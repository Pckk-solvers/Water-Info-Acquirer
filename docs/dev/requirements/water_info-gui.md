# 水文データ取得GUIの再構成

## 背景・目的

取得対象ごとに出力先・実行操作・説明の配置が分かれ、設定項目と結果を見渡しにくい。2026-10-27のユーザー依頼に基づき、設定しやすさと視認性を改善する。

## スコープ

水位・流量・雨量とダム諸量の取得GUI。CLI、取得値・品質の意味、Excelの年別シート仕様、他アプリの画面は変更しない。

## 入力

- 共通: 観測所記号（複数の貼り付けと重複除外）、取得対象、出力フォルダ、Parquetの追加出力。
- 水位・流量・雨量: 項目、開始年月・終了年月、時間値/日値、全期間シート追加。
- ダム諸量: 開始日・終了日、5項目の時間値を一括取得。

## 出力・画面

- 左に観測所一覧、右に取得条件と出力先、下に進捗と結果を置く。ウィンドウを拡大縮小できる。
- 出力フォルダを両対象で共通に指定・参照・確認でき、選択先へ実際に保存する。
- 各条件は短い補足、詳しい説明は非モーダルの「使い方」に集約する。形式と品質7種類の意味を説明する。
- 取得前に観測所・日付・期間・出力先を検証し、画面内で修正点を表示する。
- 実行中は条件編集・二重実行を防ぎ、中止を受け付ける。
- 進捗、観測所ごとの成功・品質注意・失敗・中止と詳細を画面内に残す。結果を選んでExcel/出力先を開ける。
- 成功と欠測の有無を区別し、部分取得を全件成功とは表示しない。

## 制約

- 標準Tkinter/ttkを使い、画面専用の追加依存を入れない。
- Tk操作はメインスレッド、取得・出力はワーカースレッドで行う。
- 日時の正規化と品質判定を変更しない。ダムは1観測所・要求期間でExcel1冊、年別シートを維持する。
- 中止時、ダムは取得済み分と未取得区間を保存する。水位等は完了済み観測所の出力を維持し、未完了分を成功に数えない。

## 完了条件

両対象の入力・対象切替・出力先指定・実行・結果表示・中止・失敗復帰をTkテストで確認する。通常取得の指定先保存を実ファイルで確認し、画面を画像で確認する。

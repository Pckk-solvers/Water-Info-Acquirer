# 位況・流況後処理GUI 要件

## 背景

後処理モジュールは水位と流量を同じ計算列で処理できるが、現在のExcel見出しが水位を前提としている。取得済みデータを選択して実行できるGUIを追加し、対象種別に応じた表示を提供する。

## 目的

- 取得済みの水文水質データから位況・流況をGUIで算出できるようにする。
- 水位と流量を同じ画面で扱い、対象種別に応じて説明・ラベル・出力見出しを切り替える。
- 既存の水文データ取得GUIと後処理を、ランチャーから選択できるアプリとして統合する。

## スコープ

### 含むもの

- 水位（位況）と流量（流況）の選択。
- 時間データExcelの選択。
- 日データExcelの任意選択。
- Excel出力先とParquet出力先の指定。
- 対象種別に応じた画面ラベル・出力ラベルの動的切り替え。
- 既存ランチャーおよびアプリ間メニューへの登録。

### 含まないもの

- 水文水質データベースからの取得処理。
- 雨量の位況・流況後処理。
- 既存の集計・ランク・位況計算アルゴリズムの変更。

## 入力

- 必須: 水文水質データの時間データ（`_H` Excel）。
- 任意: 水文水質データの日データ（`_D` Excel）。
- 必須: 対象種別（水位または流量）。
- 必須: Excel出力先。
- 任意: Parquet出力ディレクトリ。

ファイル名の`_WH`/`_QH`は対象種別の初期値推定に利用できるが、対象種別の最終値はGUIで選択した値とする。

## 出力

- 既存仕様の`main`、`peaks`、`summary_adj`、`summary_raw`シートを持つExcel。
- 指定時のみParquet出力。
- 水位選択時は位況・水位表記、流量選択時は流況・流量表記の見出しを出力する。

## 制約

- GUIはTkinterを使用する。
- 処理中もGUIが操作不能にならないよう、後処理はバックグラウンドで実行する。
- GUIから取得処理を開始しない。取得は既存GUIの責務とする。
- CLIの`--metric`省略時は水位として後方互換を維持する。

## 完了条件

- 水位/流量を切り替えると、画面の対象種別説明とラベル例が変わる。
- 水位/流量それぞれで出力見出しが正しい。
- 既存ランチャーからGUIを起動できる。
- 既存の取得処理、CLI、テストが継続して動作する。

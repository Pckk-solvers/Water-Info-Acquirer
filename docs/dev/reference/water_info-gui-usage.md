# 水文データ取得画面の使い方

## 起動

```powershell
uv run python main.py --app water
```

## 設定

1. 左の「観測所」にコードを入力して追加する。複数のコードを改行・空白・カンマで区切って貼り付けでき、重複は除外する。
2. 右の「取得条件」で「水位・流量・雨量」または「ダム諸量」を選ぶ。対象ごとに必要な期間の入力だけが表示される。
3. 「出力」で保存先を入力するか「参照」で選ぶ。通常取得もダム取得もこの保存先を使う。
4. 必要ならParquetの追加出力を選び、「取得を開始」を押す。

水位等は年月と時間値/日値を指定し、年別シートに全期間シートを追加できる。ダムは日付範囲を指定し、5項目の時間値をExcel1冊の年別シートと全期間CSVへ整理する。
ダムは指定先に観測所・期間のサブフォルダを作り、原データ・出典・品質情報も保存する。

## 実行中・結果

- 条件や出力先は実行中に変更できない。進捗は画面内に表示する。
- 「中止」で取得を止める。ダムは部分保存を行い、水位等は完了済み観測所の出力が残る。保存中は完了を待つ場合がある。
- 結果行を選択すると、右側に詳細と保存先が表示される。「Excelを開く」「保存フォルダ」で出力を確認する。
- 「完了」は取得・出力の完了。「品質注意」はダムの欠測等あり、「一部取得」は未取得区間あり。通常取得の欠測状況はExcelのsummaryで確認する。
- エラー内容は結果に残る。条件を修正して再実行できる。同じ条件・同じ保存先のファイルは更新される。

## 説明の表示

各入力には短い補足を表示する。右上の「使い方・品質の説明」で、手順・出力形式・品質7種類・中止・24時の扱いを別ウィンドウで確認できる。
小さい画面では上部の設定領域をスクロールして設定する。結果・実行操作は画面下に残る。

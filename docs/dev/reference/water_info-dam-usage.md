# ダム諸量の取得方法

## GUI

1. ランチャーから水文水質データ取得を開く。
2. 観測所記号を入力して「追加」。長安口ダムは `608061288803010`。
3. 「取得対象」で「ダム諸量」を選択する。
4. 開始日・終了日を `YYYY-MM-DD` で入力し、出力先を指定する。
5. ダム専用パネルの保存先を指定し、「ダム諸量を取得」を押す。31日を超える期間もそのまま指定できる。
6. 終了後、結果欄の取得状態・品質件数を確認し、「出力先を開く」でファイルを確認する。

同じ条件・同じ出力先で再実行すると保存済みの原データを再利用する。中止時は取得済み分と未取得区間の一覧を保存する。

## 出力

- 観測所と要求期間ごとのフォルダに、Excel1冊と全期間CSVを出力する。
- Excelの時間値シートは元日付の年（例:「2009」〜「2024」）。同じブックに「年別品質」「品質一覧」「出典」「取得区間」を含める。
- 整理値の単位は見出しに記載。閉局・欠測等は空欄にし、原値と属性を別列で保持する。
- `summary.json` と `取得結果.md` に全期間の品質件数と取得状態を保存する。
- 同じExcelの「年別品質」に、各年の公開行数・項目別の有効件数と欠測等をまとめる。
- 任意のParquetはダム専用の横持ち形式。既存のグラフや位況流況後処理への直接入力形式ではない。
- `raw/` に元の配布データと取得URL・ハッシュ・取得日時を保存する。
- 取得状態`complete`は通信による全区間の取得完了で、有効値が全件そろうことを意味しない。項目ごとの欠測・閉局・行欠落も確認する。
- `partial`は通信・解析等の失敗区間あり、`cancelled`は利用者の中止。失敗・未取得区間の値は埋めない。
- 12月31日24時は翌年1月1日0時の日時で、その元年のシートに含まれる。

## 保守用の再現・再開コマンド

GUIと同じサービスを呼ぶスクリプトを使用する。

```powershell
uv run python scripts/fetch_dam_data.py --code 608061288803010 --start 2009-01-01 --end 2024-12-31 --parquet --output-dir outputs/water_info/dam/608061288803010_2009_2024
```

2026-10-27にこの条件で192か月を取得・検証した。公開行133,576行、元配布データに行がない時間6,680時間。
最初の公開日時は2009-08-20 17:00。流域平均雨量には未受信48,434件がある。
成果物は上記出力先と `outputs/water_info/dam/長安口ダム_ダム諸量_2009-2024.zip` に保存した。

同日、追加依頼によりExcelを1冊の年別シートへ改良し、取得済みデータだけを使って再整理した。
最新版は `outputs/water_info/dam/608061288803010_2009_2024_再整理/` と `outputs/water_info/dam/長安口ダム_ダム諸量_2009-2024_年別シート.zip`。

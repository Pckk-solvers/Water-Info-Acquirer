# 水文水質DBの流況・位況算定手順書を追加する

## 目的

- 水文水質データベースから取得した流量・水位データを使い、流況・位況を算定する手順をリポジトリ共有時に参照できる形で残す。
- データ取得はGUI、算定は`water_info.postprocess`という現行の責務分離を明示する。
- `uv`がある環境とない環境の両方で実行方法が分かるようにする。

## 対象ファイル

- `water_info_flow_and_level_statistics_guide.md`
- `docs/dev/tasks/active/README.md`

## 実施内容

- GUIによる流量・水位の取得手順を記載した。
- `_QH/_QD`を使う流況算定と、`_WH/_WD`を使う位況算定を分けて記載した。
- `uv`利用時、Python仮想環境利用時、配布用実行ファイル利用時の起動方法を記載した。
- 後処理コマンド、算定順位、出力シート、流量利用時の名称読み替えを記載した。
- 現在は後処理GUIと入力種別に応じた出力名称が未対応であることを記載した。

## 完了条件

- リポジトリ直下の手順書だけで、GUI取得から流況・位況算定までの操作が分かる。
- CLIによるデータ取得を前提とした記述がない。
- `uv`がない環境でもPython仮想環境を使った実行方法が分かる。
- 流況と位況の入力ファイル、結果名称、現在の制約が区別されている。

## 確認方法

- ユーザー指示により、ドキュメント作業のため追加の実行検証は行わない。

## 結果

- リポジトリ直下に`water_info_flow_and_level_statistics_guide.md`を追加した。
- データ取得をGUI利用に統一し、CLIによる`fetch`手順を除外した。
- `uv`あり・なしの環境準備と実行方法を追加した。
- 流況・位況の双方を対象とする構成へ整理した。

## 残課題

- 流況・位況算定専用GUIの追加。
- 入力種別を明示する設定と、流量・水位に応じた出力名称の切り替え。
